# rib — Rust Image Builder

**rib** — rootless-сборщик OCI-образов, реализованный на Rust и названый как
отсылка к идейному вдохновителю, проекту [Jib](https://github.com/GoogleContainerTools/jib). Он предназначен для упаковки уже подготовленных артефактов и runtime-файлов без Docker daemon,
privileged-контейнера и выполнения команд внутри собираемого образа.

`rib` формирует воспроизводимые `COPY`-слои файловыми операциями и публикует
результат непосредственно в registry, OCI archive или Docker archive.

## Для каких задач подходит rib

`rib` следует использовать, когда приложение уже собрано и требуется:

- упаковать бинарник, фронтенд или любой другой набор файлов в
  OCI-образ;
- выполнять сборку образа без root-доступа и container runtime;
- встроить упаковку и подпись образа в CI/CD-конвейер.

`rib` не реализует работу с Dockerfile. Если подготовка образа требует `RUN`
или других специфических команд, следует использовать Dockerfile-совместимый
сборщик, например [BuildKit](https://github.com/moby/buildkit) или
[Buildah](https://github.com/containers/buildah).

`rib` можно включить непосредственно в образ сборочного окружения, чтобы
использовать стандартное кэширование образов Docker или Kubernetes. При
повторной упаковке не требуется обязательный предварительный `pull` базового
образа: его rootfs не разворачивается полностью без необходимости.
